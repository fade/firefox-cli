Firefox CLI 0.4.0 adds explicit browser-focus controls and fixes file uploads rejected because their file type was missing.

- Navigation and new tabs run without requesting window focus by default. Use `--focus` with `open`, `tab new`, `window new`, or `screenshot` when you want Firefox brought forward.
- Screenshots select the requested tab without raising its window unless `--focus` is supplied.
- Uploads identify PNG, JPEG, BMP, and other recognized file types from their filename extensions.

**Upgrade:** Update the CLI and Firefox extension together. Run `firefox-cli setup` after updating the CLI to install the matching extension.
